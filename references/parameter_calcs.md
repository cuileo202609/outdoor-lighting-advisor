# 参数配比计算方法

优先使用 `scripts/lighting_calc.py`，以下为公式依据。

## 1. 流明法（估灯数量）

```
N = (E × A) / (F × CU × MF)
```
- E：目标维持照度 (lx)
- A：照明面积 (m²)
- F：单灯光通量 (lm)
- CU：利用系数，泛光灯取 0.6–0.75，路灯按配光取 0.3–0.5
- MF：维护系数，室外取 0.7–0.8（污染重取低值）

## 2. 太阳能系统配比

```
日耗电量 Wh = LED功率(W) × 每晚工作时长(h)
电池容量 Wh = 日耗电 × 续航天数 / DOD（锂电池 DOD 取 0.8–0.9）
光伏板功率 Wp = 日耗电 × (续航天数+1) / (日照时数 × 系统效率0.75)
```

示例：60 W 灯每晚亮 8 h，日照 4 h，续航 3 个阴雨天：
- 日耗电 = 60×8 = 480 Wh
- 电池 = 480×3 / 0.8 = 1800 Wh（12V 系统 ≈ 150 Ah）
- 光伏板 = 480×4 / (4×0.75) = 640 Wp

实际工程中通常取计算值上浮 10–20% 余量；感应降功率模式可显著缩小配比。

## 3. 杆高与间距经验比值

- 路灯：间距 ≈ 杆高 × 3～3.5（单侧布灯），双侧交错可放宽
- 悬挑臂长 ≈ 杆高 × 0.1；灯杆埋深 ≈ 杆高 × 1/6～1/8
- 投光灯：安装高度应 ≥ 光束射程对应照度需求，窄光束远投、宽光束近铺

## 4. 光束角选择

| 光束角 | 用途 |
|-------|------|
| 15–30° | 高杆远投、立面泛光 |
| 45–60° | 常规投光、球场 |
| 90–120° | 庭院、停车场、近距离铺光 |

## 5. 电线压降（市电长距离布线）

```
ΔV% = (2 × L × P × ρ) / (S × U²) × 100
```
- L：线长 (m)，P：功率 (W)，ρ：铜电阻率 0.0175 Ω·mm²/m，S：线径 (mm²)，U：电压 (V)
- 要求 ΔV ≤ 3–5%，超了就加大线径。

## 6. 常用参数合理区间校验（防虚标）

- LED 光效：市电灯 100–160 lm/W；高于 200 lm/W 的宣称要怀疑
- 显色指数：道路 Ra≥60 可接受，庭院/景观建议 Ra≥70–80
- IP 等级：户外至少 IP65；埋地/水下需 IP67–IP68
- 防雷：市电路灯建议驱动的耐浪涌 ≥ 4–6 kV，多雷区 10 kV
- 太阳能电池：磷酸铁锂循环寿命 ≥ 2000 次
