# 户外灯具选型指南

## 选型五要素（缺一先追问）

1. **应用场景**：道路 / 庭院 / 广场 / 停车场 / 工业厂房 / 球场 / 隧道 / 港口
2. **几何条件**：照明面积或道路宽度、安装高度、杆距
3. **供电条件**：有市电 → LED 市电灯具；无市电或布线成本高 → 太阳能
4. **环境条件**：沿海（防盐雾）、多尘、高温/严寒、防爆要求
5. **规范要求**：是否需满足市政验收（CJJ 45 城市道路照明设计标准）

## 照度目标速查（维持平均照度，参考 GB 50034 / CJJ 45 常用值）

| 场景 | 建议照度 (lx) |
|------|--------------|
| 主干路 | 20–30 |
| 次干路 | 10–15 |
| 支路/小区道路 | 8–10 |
| 庭院/景观 | 5–10 |
| 停车场 | 10–20 |
| 一般工厂车间（高天棚） | 100–200 |
| 篮球场（休闲） | 150–300 |
| 足球场（训练） | 200+ |

## 选型决策树

```
有无市电？
├─ 有市电
│   ├─ 道路 → LED路灯（杆高决定功率）
│   ├─ 大面积/高天棚 → UFO工矿灯/投光灯
│   └─ 景观/泛光 → 投光灯/洗墙灯/线条灯
└─ 无市电
    ├─ 道路 → 太阳能路灯（分体/一体化）
    ├─ 庭院 → 太阳能庭院灯/草坪灯
    └─ 投光 → 太阳能投光灯
```

## 常见品类推荐功率对照（LED，光效按 100–160 lm/W 区间）

| 杆高/安装高度 | 道路宽度 | 建议单灯功率 |
|--------------|---------|-------------|
| 4–5 m 庭院灯 | 3–4 m | 20–40 W |
| 6–8 m 路灯 | 6–8 m | 50–100 W |
| 8–10 m 路灯 | 8–12 m | 80–150 W |
| 12 m 以上主路 | 15 m+ | 150–250 W |
| 高天棚 6–8 m | — | 100–150 W |
| 高天棚 10–15 m | — | 200–400 W |
| 球场灯杆 8–15 m | — | 200–500 W/灯 |

注意：以上为经验值，最终以照度计算（`lighting_calc.py lumen`）复核为准。低品质灯具标称功率虚高，应要求供应商提供配光曲线与实测流明报告（LM-80 / IES 文件）。

## 太阳能灯选型要点

- **分体式**：电池板与灯体分离，功率可做大，适合道路；安装复杂。
- **一体化**：紧凑、安装快，适合支路、庭院；功率上限较低。
- 必问信息：当地日均峰值日照时数、最长连续阴雨天数、每晚亮灯时长（全亮 or 感应+降功率）。
- 警惕虚标：标称"1000W"的太阳能一体化灯实际 LED 功率多为 30–100 W，认准实际 LED 输入功率与电池容量（Wh）。
