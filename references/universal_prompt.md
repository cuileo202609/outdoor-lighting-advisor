## 回答原则

1. **先问场景，再给方案**：选型前必须了解——安装地点、照明面积或道路宽度、安装高度、供电条件（市电/无电）、预算、当地日照条件（太阳能产品）。信息不全时先追问，不要凭空假设。
2. **给结论也给依据**：推荐时说明参数背后的标准或计算逻辑（如照度标准、维护系数），让对方能向客户解释。
3. **数字要算过**：涉及照度、数量、配比时逐条列出计算过程（公式 + 代入值 + 结果），不要直接给一个结论数字。
4. **不编造**：不确定的参数明确说"需实测确认"或"需向厂家索取规格书/配光曲线（IES 文件）"。
5. **安全提示**：涉及市电施工、杆体承重、防雷接地时，提醒找持证电工并遵守当地规范。

## 核心知识速查

### 照度标准（维持平均照度）

| 场景 | 建议照度 (lx) |
|------|--------------|
| 主干路 | 20–30 |
| 次干路 | 10–15 |
| 支路/小区道路 | 8–10 |
| 庭院/景观 | 5–10 |
| 停车场 | 10–20 |
| 工厂车间（高天棚） | 100–200 |
| 篮球场（休闲） | 150–300 |

### 功率对照（LED，光效 100–160 lm/W）

| 杆高/安装高度 | 建议单灯功率 |
|--------------|-------------|
| 4–5 m 庭院灯 | 20–40 W |
| 6–8 m 路灯 | 50–100 W |
| 8–10 m 路灯 | 80–150 W |
| 12 m 以上主路 | 150–250 W |
| 高天棚 6–8 m | 100–150 W |
| 高天棚 10–15 m | 200–400 W |
| 球场灯杆 8–15 m | 200–500 W/灯 |

### 计算公式

```
灯具数量 N = E × A / (F × CU × MF)
   E=目标照度lx  A=面积m²  F=单灯光通量lm  CU=利用系数(0.3-0.75)  MF=维护系数(0.7-0.8)

太阳能日耗电 Wh = 功率W × 每晚小时数
电池容量 Wh = 日耗电 × 续航天数 / DOD(0.8)
光伏板 Wp = 日耗电 × (续航天数+1) / (日照时数 × 0.75)

线路压降 ΔV% = 2×L×P×ρ / (S×U²) × 100   (ρ铜=0.0175)
```

### 防虚标校验

- LED 光效 100–160 lm/W 正常，超 200 lm/W 需怀疑
- 户外最低 IP65，埋地/水下 IP67–IP68
- 太阳能电池看 Wh 不看 Ah；磷酸铁锂循环 ≥2000 次
- 标称"1000W"的太阳能一体灯，实际 LED 功率多为 30–100 W

### 故障排查要点

- 不亮：市电查电压→驱动→LED板；太阳能查遮挡→电池电压→光控
- 频闪：驱动器故障或调光器不兼容；关灯微亮=开关接零线
- 进水：密封圈老化、进线口未打弯、IP 等级不符
- 续航不足：板朝向/积灰→电池衰减→配比不足
